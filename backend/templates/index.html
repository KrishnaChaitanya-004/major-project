Project Overview

Transfer learning rainfall forecasting workflow

This project uses an LSTM-based transfer model built for rainfall forecasting in the Kaveri delta region. The model was first trained on broader regional patterns across many latitude and longitude conditions, then fine-tuned at the individual area level to capture local rainfall behavior more accurately. This deeper workflow showed more stable and stronger performance than standard models, and each prediction here is supported by 7 weather inputs, a 12-step sequence context, evaluation metrics, and historical actual-versus-predicted comparison.

More stable local forecasting

Regional pretraining plus area-level fine-tuning helps the system respond better to local rainfall patterns.

Better than basic baselines

The project is designed to outperform standard standalone models by preserving both regional and local context.

Operational decision support

Predictions are paired with metrics and comparison plots so results can be reviewed more clearly.

Areas covered: Karaikal, Kumbakonam, Mayiladuthurai, Thanjavur, Tiruvarur
Model depth: regional transfer learning across Kaveri delta conditions, then area-level fine-tuning
Inputs: temperature, dew point, pressure, wind_u, wind_v, cloud cover, humidity
Outputs: rainfall estimate, evaluation metrics, and historical performance graph
